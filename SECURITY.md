# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad en este proyecto, **no abras un issue público**.

Repórtalo de forma privada desde la pestaña **Security → Report a vulnerability** de este repositorio.
Revisaremos cada reporte y responderemos lo antes posible.

Por favor incluye:
- Descripción del problema y su posible impacto
- Pasos para reproducirlo
- Versión o URL afectada

## Alcance

Aplica al código de este repositorio y a su despliegue en producción.
Nunca publiques claves, datos de usuarios ni detalles de explotación antes de que el problema esté corregido.
